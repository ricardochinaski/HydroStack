# Firebase

El repositorio no contiene todavía reglas, índices ni configuración desplegable de Firebase versionados. La integración está implementada dentro de la app Flutter y de los firmwares ESP8266/ESP32-CAM.

Consulta [`docs/firebase.md`](../docs/firebase.md) para las rutas y servicios confirmados. Los archivos de configuración y secretos locales están excluidos por `.gitignore` y no deben agregarse a este directorio.
