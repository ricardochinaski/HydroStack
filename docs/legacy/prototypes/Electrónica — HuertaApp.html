// PASOS DE CABLEADO SEGUROS

① Alimentación — SIEMPRE primero

Conecta la fuente 5V externa al relay (VCC y GND). El ESP32 va por USB o fuente propia 3.3V. NUNCA alimentes el relay desde el pin 5V del ESP32.

⚠️ El relay consume hasta 360mA por canal. El pin 5V del ESP32 sólo da 500mA total.

② DHT22 — Temperatura y Humedad Ambiente

VCC → 3.3V del ESP32
GND → GND del ESP32
DATA → GPIO4
Resistencia pull-up de 10kΩ entre DATA y VCC. Ya viene integrada en muchos módulos breakout.

③ DS18B20 — Temperatura Agua (sumergible)

Cable rojo (VCC) → 3.3V
Cable negro (GND) → GND
Cable amarillo (DATA) → GPIO13
Resistencia pull-up de 4.7kΩ entre DATA y VCC. Obligatoria, sin ella no funciona.

④ HC-SR04 — Nivel de agua

VCC → 5V externo (trabaja a 5V, no 3.3V)
GND → GND
TRIG → GPIO5
ECHO → GPIO18 (con divisor de voltaje 1kΩ + 2kΩ para bajar 5V → 3.3V)

⑤ Módulo Relay — Control Bomba

VCC → 5V externo
GND → GND compartido
IN1 → GPIO26 (bomba principal)
IN2 → GPIO27 (ventilador)
IN3 → GPIO14 (luz UV, opcional)
La bomba 220V se conecta a COM y NO (Normally Open) del relay 1.

⚠️ 220V es peligroso. Usa cable bien aislado y caja cerrada para los terminales de alta tensión.

⑥ Sensor Humedad Suelo (Capacitivo)

VCC → 3.3V
GND → GND
AOUT → GPIO34 (pin ADC solo de entrada)
Calibrar: 100% húmedo (~1000) y completamente seco (~3000) para mapear porcentaje.

// CONEXIONES ADICIONALES PRO

⑦ Sensor pH — Gravity SEN0161

VCC → 5V externo (o 3.3V si tienes V2)
GND → GND
AOUT → GPIO35 (ADC pin)
Calibrar con buffer pH4 y pH7. Enjuagar sonda con agua destilada entre mediciones.

⚠️ La sonda de pH dura ~1–2 años. Mantener en solución KCl cuando no se usa.

⑧ Sensor EC — SEN0244

VCC → 5V
GND → GND
AOUT → GPIO32
No instalar cerca del sensor pH para evitar interferencias electromagnéticas.

⑨ Pantalla TFT 2.8" ILI9341

VCC → 3.3V
GND → GND
CS → GPIO15 | RESET → GPIO4 | DC → GPIO2
MOSI → GPIO23 | CLK → GPIO18 | LED → 3.3V
Librería: TFT_eSPI (configurar pins en User_Setup.h)

⑩ Bombas Peristálticas × 2

Bomba 12V DC. Conectar a fuente 12V independiente.
Control por relay: IN5 → GPIO25 (nutriente A)
IN6 → GPIO33 (nutriente B)
Ciclo: 5 segundos de bomba = ~4mL de nutriente. Calibrar por volumen real.

💡 Reglas de oro para el cableado 1. GND común para todo: ESP32, relay, sensores y fuente externa deben compartir el mismo negativo.
2. Color de cables: Rojo = VCC, Negro = GND, Verde = señal/datos, Amarillo = ADC.
3. Nunca tocar 220V con el circuito encendido. Desconectar antes de cualquier cambio.
4. Prueba sin 220V primero: verifica que los relays "hacen clic" antes de conectar la bomba real.
