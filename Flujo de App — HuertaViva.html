S-04 · Conectar ESP32
Conecta tu huerta al WiFi
El momento más crítico del onboarding. Tiene que ser ultra simple.
Todos
Pasos que ve el usuario
  • ① Conecta el cable de la huerta
  • ② La app detecta el ESP32 por Bluetooth
  • ③ App le manda el WiFi del hogar
  • ④ ESP32 se conecta solo
  • ⑤ ✅ "¡Tu huerta está conectada!"
Cómo funciona
  • ESP32 en modo "provisioning"
  • App usa BLE para enviar credenciales
  • ESP32 registra su ID en Firebase
  • App verifica conexión en 30 seg
  • Guardar ESP32 ID en el perfil
🔥 Firestore: huertas/{esp32_id} 📱 flutter_blue_plus

S-13 · Riego Manual
Regar ahora
El cliente activa la bomba manualmente desde el celular.
Inteligente+
Flujo del usuario

  • Confirmación: "¿Regar 10 minutos?"

  • "✅ Riego completado"
Lo que pasa en el ESP32
  • App escribe en Firebase: regar=true
  • ESP32 lee el cambio en milisegundos
  • Activa relay → bomba ON
  • Timer interno en ESP32
  • Bomba OFF al terminar

📱 Capa UI — Las pantallas

Riverpod o Provider maneja el estado. Cuando llegan datos nuevos de Firebase, las pantallas se actualizan solas. Aquí vive la lógica de "¿qué modo es el usuario?" y "¿qué alerta mandar?".

providers/ controllers/ models/

☁️ Capa Datos — Firebase

Servicios que hablan con Firebase: autenticación, Firestore, Cloud Messaging. Aquí también está la llamada a la API de Anthropic para el diagnóstico de plantas con IA.

services/auth services/firestore services/ai services/notifications

🧠 ESP32 — Hardware

El ESP32 se comunica con Firebase directamente (no con la app). Escribe datos de sensores cada 5 minutos y lee comandos en tiempo real. La app nunca habla directo al hardware.

Arduino C++ Firebase ESP32 library WiFi.h
