# Hardware

No hay todavía un paquete canónico independiente de diagramas, cableado y BOM para el hardware activo. La información confirmada se deriva de los firmwares y está consolidada en [`docs/hardware.md`](../docs/hardware.md).

Los diagramas y listas de compra encontrados corresponden a prototipos anteriores y se preservan bajo `docs/legacy/`. Cuando exista una revisión física validada del conjunto Mega + ESP8266 + ESP32-CAM, este directorio podrá separar sus diagramas, cableado y BOM sin mezclarlo con material histórico.
